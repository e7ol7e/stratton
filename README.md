# Бот для изучения слов

Telegram-бот на Python 3.10+ и aiogram 3.x. Работает в личных сообщениях через long polling.

**Попробовать бота:** [@stratton_words_bot](https://t.me/stratton_words_bot) — откройте в Telegram и нажмите «Старт».

## Запуск

1. Создайте бота в Telegram через @BotFather и получите токен.
2. Установите [uv](https://docs.astral.sh/uv/getting-started/installation/) и зависимости:

   ```powershell
   uv sync --locked
   Copy-Item .env.example .env
   ```

3. Укажите `BOT_TOKEN` в `.env`.
4. Запустите:

   ```powershell
   uv run --locked python -m bot
   ```

На Linux/macOS для копирования настроек используйте `cp .env.example .env`; команды uv одинаковы. Запускайте из корня проекта. uv автоматически создаёт `.venv`; точные версии зависимостей закреплены в `uv.lock`. Для одного токена нужен один процесс бота; ранее настроенный webhook необходимо отключить перед polling.

## Docker Compose и VPS

Контейнерный запуск: `docker compose up -d --build` (при заполненном `.env` и запущенном Docker). Перед запуском остановите локальный процесс бота. На Linux подготовьте права каталогов по инструкции [DEPLOY.md](DEPLOY.md). Там же описаны перенос базы на VPS, обновление и резервное копирование. Данные хранятся в `./data`, логи — в `./logs`.

## Возможности

- `/add`: FSM последовательно запрашивает слово и один перевод. Повторные слова не добавляются; регистр и пробелы при поиске дублей игнорируются.
- `/test`: до 10 случайных слов без повторений. Ответ вводится текстом. Сравнение игнорирует регистр, повторные пробелы и различия Unicode NFKC; синонимы и опечатки автоматически не распознаются.
- `/stats`: количество слов, завершённых тестов, правильных ответов и общая точность по всем ответам.
- `/words`: последние 10 добавленных слов.
- `/cancel`: отменяет ввод или тест; незавершённые тесты не учитываются.
- `/start` и `/help`: справка и сброс текущего диалога.

Данные разных пользователей изолированы по Telegram ID. SQLite создаётся автоматически в `data/vocabulary.sqlite3`; путь можно изменить через `DATABASE_PATH`. Слова и результаты сохраняются после перезапуска. FSM хранится в памяти, поэтому незавершённый диалог при перезапуске сбрасывается. Обработка сообщений одного пользователя сериализована, чтобы быстрые ответы не повреждали состояние теста.

Ошибки обработчиков перехватываются, диалог сбрасывается, пользователь получает уведомление. Логи пишутся в консоль и `logs/bot.log` с ротацией. Уровень задаётся через `LOG_LEVEL` (по умолчанию `INFO`). Не публикуйте `.env`, базу и логи.

## Проверка

```powershell
uv run --locked python -m unittest discover -s tests -v
```

Документация: [FSM aiogram](https://docs.aiogram.dev/en/latest/dispatcher/finite_state_machine/index.html), [обработка ошибок](https://docs.aiogram.dev/en/latest/dispatcher/errors.html).
